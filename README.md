# KataCity 救急隊用指名手配リスト

このサイトは、救急隊員のみなさんが【相手が現在警察から指名手配されている人物かどうか】を確認するための専用サイトです。
あくまで参考程度に、救急業務補助としてお使いください。

ちなみにこのサイトの完全上位互換として[ボブさん作のビュワーアプリ](https://github.com/gtabob1016/WantedViewer/releases)があります。こちらもご自由にお使いください。

<details>
##  <summary>仕組みとデータの更新について（重要）</summary>

- 街六法の指名手配リストと手動で連動させているだけですので**警察とはなんの関係もございません。**
  
- このサイトは、フォームに入力された指名手配データをそのまま自動で表示するサイトです。そのため、一般の隊員がサイト上で直接データを書き換えることはできません。
  - 例外：逮捕済みチェックは入れても問題ありません
    
- 現在フォームに入力できるのは***診療部長以上のみ***です。
  - ボブさん作のビュワーアプリでは誰でもフォームに送れるようになっていますが、指導医およびレンジャー以下の方々は送らないようお願いします。
    
- サイトの情報は*約5分ごとに自動で更新*されています。データが切り替わるまで少し時間がかかる場合がありますが、ブラウザの更新ボタン（再読み込み）をむやみに連打しないでください。
  
- サイトのサイズやモード・名前非表示などは、他の人の画面には影響しません。みなさん各自のパソコン・スマホ環境（ブラウザの設定など）に合わせて、見やすいように自由にいじってもらって大丈夫です。
  - ボブさん作のビュワーアプリでは逮捕済みチェック入れると全員に反映されるのでご注意ください

<summary>##  よくある質問（FAQ）</summary>

Q. 新しい手配犯が追加されたはずなのに、画面に表示されません。  
A. データが反映されるまで最大5分ほどかかります。更新ボタンを何度も連打せず、少し待ってから確認してください。

Q. サイトの文字が小さくて見づらいです。  
A. 画面の表示は各自の環境に依存しているため、お使いのブラウザ（ChromeやEdgeなど）の拡大機能を使って、見やすい大きさに各自で調整してください。変更しても他の人の画面は変わりませんので安心してください。

Q. 自分がフォームのデータを追加したり、消したりしたいです。  
A. 現在フォームへ投稿・編集できるのは診療部長以上のみに制限されています。サイト上への追加や削除が必要な場合は、データ管理の権限を持つ人へ依頼するか、サイト上で非表示にするか、時間経過で消えるのを待ってください。

Q. 名前が被ってる人がいるんだけど…  
A. 現在は、指名手配がまるっきり同じ人は被らないようになっていますが、一人でも名前が違う人と上がると別物としてサイト上に表示される仕様になっています。ちなみにそのあたりはボブさん作のビュワーアプリが完全上位互換となっています。
